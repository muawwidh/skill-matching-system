# Live Jobs on the Development Database (2026-11-21)

First import of live jobs (D052-D058), its cost, the Jobs page latency, and a
check that the Phase 5 evaluation set is unaffected. Development database,
Docker on one laptop (CPU only). Snapshot taken before the import:
`~/skillgap-db-snapshots/skillgap-pre-live-import-20261121T131017Z.dump`
(outside the repository).

## Import

Run `import-live-jobs` with `LIVE_JOBS_MAX_ACTIVE=1000` for this run only, before
the per-source share (D058) existed. Arbeitnow (10 pages) and 20 Greenhouse
boards, no fetch errors.

Totals come from the run report. The run report did not split skips by
source; the per-source values (~) come from repeating fetch and selection
without database writes about three hours later, so they differ slightly.
Non-English by language: de 795, fr 281, nl 130, it 47, pt 22, es 7, pl 2,
sv 1, unknown 1. Contact details removed: 537 e-mail addresses, 162 phone
numbers, 67 names.

Skills: 7.36 extracted skills per job (Arbeitnow 7.19, Greenhouse 9.67;
24 Arbeitnow jobs have none). 75.7 % of job skills have an automatically
approved taxonomy link (Arbeitnow 75.5 %, Greenhouse 78.2 %). 7,192 extracted
terms have 956 distinct normalized texts. 20,184 link suggestions were left
pending.

Time: 11,007 s in total: about 50 s fetching, 3 h 00 min pipeline
(11.1 s per job), 155 s embedding all 977 jobs in one batch (0.16 s per job).
Per job, extraction took about 0.005 s and taxonomy linking the rest.

Newest-first selection favoured Arbeitnow, whose postings are newer: 911 of
977 jobs. D058 now limits each source to 70 % of the cap.

## Taxonomy linking speed-up

Linking loaded all 22,259 active concepts and 170,721 labels twice per job
(about 3.1 s each) and scanned every label for every term (about 0.08 s per
term). It now uses a cached in-memory index
(`app/taxonomy/concept_index.py`).

Measured end to end on a disposable copy of the database, re-linking the same
50 live jobs, without embedding:

| | Old | New |
| --- | --- | --- |
| Linking per job, mean | 7.47 s | 0.099 s |
| Linking per job, median | 7.34 s | 0.082 s |
| First job | 8.73 s | 0.74 s (builds the index) |
| Link candidates / automatic links | 1,175 / 254 | 1,175 / 254, identical (digest) |

Read-only check on the development database for all 333 terms (183 distinct)
of these jobs: the old linker, the new index and the suggestions stored by the
import agree on every candidate, method, confidence and automatic approval
(0 mismatches, 254 automatic approvals each). The full pipeline time per job
will be confirmed by the next import.
